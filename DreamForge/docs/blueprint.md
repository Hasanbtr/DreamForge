# **App Name**: DreamForge

## Core Features:

- Idea Feed: Display a feed of product ideas, categorized by popularity, recent submissions, and category.
- Idea Detail Page: Display detailed information about each product idea, including 3D model viewer (Three.js), funding progress, and user comments.
- Product Idea Submission: Allow users to upload product ideas with details like name, description, 3D design file (STL/OBJ), funding goal, production timeline, and category.
- Voting & Pre-ordering: Enable users to vote for ideas and pre-order products.
- User Dashboard: Display a dashboard for users to manage their submitted ideas and track pre-orders.
- AI-Powered Product Description Generator: AI tool to generate creative product descriptions based on provided keywords and design files.

## Style Guidelines:

- Primary color: Vibrant purple (#A050BE) to convey creativity and innovation.
- Background color: Light grey (#F0F0F0), providing a neutral backdrop to make the primary color stand out.
- Accent color: Soft teal (#50BEA0), used sparingly to draw attention to calls to action and interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif, lending a modern, machined, objective, neutral look. It is suitable for both headlines and body text.
- Use minimalist, line-based icons to represent product categories and functionality, ensuring clarity and ease of understanding.
- Employ a card-based layout to showcase product ideas, with a clean and responsive design adaptable to various screen sizes.
- Implement subtle transitions and animations when loading content or interacting with elements to provide a polished user experience.
